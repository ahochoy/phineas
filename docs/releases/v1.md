## Deliberate limitations

Public inputs are synthetic only. No uploads, bank connection, financial advice,
long-term records, recovery page, or background notifications. Session expiry is
30 minutes idle/four hours absolute; refresh loses tab access but does not purge
server records. TTL is eventual cleanup, not a precise deletion timer.

Password possession is not recruiter identity; recipients can share it. Edge
limits are approximate/per-location, gateway throttles are best-effort, and
question quotas/budgets are not hard monetary caps. Some public metadata/preview
requests still consume infrastructure resources. Existing queued work can finish
after access is paused. Models can produce imperfect explanations even when
structural/numeric validation passes. The stopped Sonnet evaluation is historical
evidence, not a deployed model change.
